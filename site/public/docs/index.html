Install Omarchy Pocket

Omarchy Pocket puts Omarchy's command line, themes, menu and services under one shell made for handhelds. Each device takes it its own way. Pick yours.

From source

Anbernic RG DS Plus

The SD card's system

Replaces the stock launcher; the stock system stays as the rescue boot. Built and installed from source.

From the release

AYN Thor

An Android app

Install the app, give it the Linux root, play. Nothing rooted, nothing replaced.

From the release

ClockworkPi uConsole

A Debian package

One apt install beside Raspberry Pi OS. Its menu gives the panel back to the desktop.

One shell, three machines

The same shell runs on all three: Omarchy's bar, its menu, windows tiled the way Omarchy tiles them, Pocket Term, and the applets. What changes is how your hands reach it.
