AYN Thor

An Android app. Nothing rooted, nothing replaced: the upper screen is the monitor, the touch screen the keyboard and trackpad, the Odin controller the gamepad.

Release

Runs on
The AYN Thor on AYN's Android 13 firmware
Space
3.5 GB free: the 802 MB root, unpacked into the app's own files
Time
About 10 minutes

Install

  1. On the Thor, open the release in the browser and download omarchy-pocket-0.2.0.apk and omarchy-pocket-root.tar.zst.
  2. Open the APK and install it. Android asks once to let the browser or the file manager install apps.
  3. Open Omarchy Pocket. With no Linux root yet, the upper screen says so. Press START, and pick omarchy-pocket-root.tar.zst in the file picker. The app copies it and unpacks the root, which takes a few minutes.
  4. Unlock with the password omarchy.
A Thor with a build from source on it (signed with the debug key) has to uninstall that first, which removes its root: Android installs an update only over the same signature.

Controls

The shoulders are SUPER. Hold L1 for the window layer and R1 for the move layer, both for workspaces. After a quarter of a second, the lower screen draws the buttons around it and what each does. With no shoulder held, the gamepad types: the D-pad is the arrows, A Enter, B Backspace, X Tab, Y Space, START Escape. SELECT shows the keys or folds them away; L1 + SELECT lists everything.

The film

Update and uninstall

  • Update: install a newer APK over this one. The root stays, and the app puts the new release's daemon and applets into it.
  • Uninstall: Settings › Apps › Omarchy Pocket › Uninstall. That removes the root too.

Limits

  • Programs in the Linux root play no sound. Android's volume and mute work.
  • AYN's Burn-in Protection Refresher covers both screens from time to time while they are still, and takes the next press.
  • GitHub and Weather are left out at the Thor's density for now.
