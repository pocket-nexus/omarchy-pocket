# Omarchy features in Omarchy Pocket

Omarchy's desktop is Hyprland plus a Quickshell shell (`/usr/share/omarchy/shell`: the bar, the menu and about 30 plugins). Omarchy Pocket keeps Omarchy's CLI, config, themes and services and replaces the desktop with its PocketJS shell. This table lists each part of Omarchy's desktop and its state on the RG DS Plus. **Done** means it ran on the device; the date is the last check.

| Omarchy part | Omarchy Pocket | State |
|---|---|---|
| Menu (`omarchy-menu.jsonc`, `omarchy.menu` plugin) | the stage's card, worked from the gamepad or the deck's keyboard, which filters each level by typing as the walker menu does: Omarchy's tree, `when`/`checked`/`disabled` from the daemon, actions through the daemon, `shell summon omarchy.menu {"menu":…}` | done 2026-10-29; typing filters since 2026-10-31 |
| Proxy (Clash Verge Rev's core) | mihomo on the device as `mihomo.service` with the Mac's profile; the Proxy panel (bar and map indicator, Setup › Proxy, `shell summon omarchy.proxy`): on/off, mode, each selector group's node and latency test (`daemon/proxy.ts`) | done 2026-10-29: discord.com 0.2 s, youtube.com 0.5 s through it |
| Agent (`omarchy agent`, SUPER + SHIFT + CTRL + A) | the dock's Agent cell: Omarchy's default coding agent in a Pocket Term window (`omarchy-agent --inline --pick`); Codex 0.162.1 from Omarchy's repo with the Mac's ChatGPT login, through mihomo | done 2026-10-29: Codex's TUI in a window, `codex exec` runs commands on the device; the device needs zram and earlyoom for it (docs/omarchy-pocket.md › Memory) |
| System › Lock | `omarchy-system-lock` → `lock lock` → clock on the stage, password on the touch keyboard (A Enter, B Backspace); omarchy-pocketd checks it with `unix_chkpwd`. | Windows and workspaces (Hyprland dwindle and scrolling, Omarchy's gaps, border and window animations) | `shell/src/wm.ts`: five workspaces, each a dwindle tree or a scrolling strip (toggle keeps order and focus); focus, swap, resize, toggle split, swap split, column widths, stack and unstack, fullscreen, maximize, carry, reopen. Windows move on the core's animation tracks (FLIP): they ease between placements in 200 ms, pop in from 87 %, leave a shrinking outline, and slide 48 points when the workspace changes | done 2026-10-29 (open, swap, close, layout, workspace switch captured mid-flight on the device; a split presents 14–15 frames at 16–17 ms) |
| Keybindings (SUPER + key, the SUPER + K sheet) | Pocket Shell's 3DS grammar (`shell/src/chords.ts`, one table for the dispatcher, the legend and the key sheet): L1 window layer, R1 move layer, L1 + R1 workspace layer, each lasting as long as its shoulder; with no shoulder the buttons are keys for whatever has focus (D-pad arrows, A Enter, B Backspace, X Tab, Y Space, START Escape), SELECT turns the deck's layout, L2/R2 switch workspaces. A shoulder held a quarter second shows its layer's legend on the stage. The gamepad's X and Y follow the stock SDL entry for `ANBERNIC-keys` (X 307, Y 306). docs/interaction.md states the system | done 2026-10-29; redone 2026-10-31 |

| Text beyond the baked ranges (CJK, Cyrillic, Latin Extended, Nerd Font icons) | omarchy-pocketd bakes the characters the shell meets (terminal cells, menu labels, candidates) with PocketJS's `bakeSlot` into font slots 21 (12 px) and 22 (14 px), from JetBrainsMono Nerd Font with wqy-microhei for what it lacks; emoji that command-line tools print become the Nerd Font icon for the same thing (starship's 🔒).
